**# Datheon Machine Learning & Data Science Internship

## Task: Supervised Classification on Iris Dataset

### Project Overview
This project implements a supervised machine learning classification pipeline using the Iris dataset. It compares the performance of **Logistic Regression** and **Decision Tree Classifier** models.

### Workflow & Key Steps
1. **Exploratory Data Analysis (EDA):** Visualized feature distributions using Seaborn pairplots.
2. **Data Preprocessing:** Handled feature scaling using `StandardScaler` and split the dataset into 80% training and 20% testing sets.
3. **Model Training:** Trained `LogisticRegression` and `DecisionTreeClassifier`.
4. **Evaluation:** Evaluated model performance using Accuracy, Precision, Recall, F1-Score, and Confusion Matrix heatmaps.
5. **Decision Boundary:** Visualized model decision boundaries in a 2D feature space.

### Tech Stack
* Python
* Scikit-Learn
* Pandas & NumPy
* Seaborn & Matplotlib**
